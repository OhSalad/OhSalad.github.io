The project, beyond the download

What has changed in
Tales of Pirates DX

We've been working on the systems behind the game: reducing server idle work, making updates recoverable, expanding inventory, and fixing movement, trading, and pet progression. Here is what we've added and improved.

Project changes reviewed through October 7, 2026. Some recent source changes may require a later client update or server rollout.

Less repeated work

Optimizations with a clear purpose

~60% lower idle-server container CPU Observed in the corrected October 6 test-VPS comparison, with zero connected clients.

Wake when there is work to do

The network dispatchers previously woke every 2 milliseconds to check for work. An interruptible wake channel lets them wait and wake promptly when work arrives. Idle worker pools also wake explicitly during shutdown.

The corrected comparison recorded container CPU at 192–214% before and 68–84% after, where 100% equals one CPU core. The shared host's load differed between windows. This is a scoped idle measurement, not an official performance baseline or a claim about player FPS or busy-server throughput.

Client rendering

Less work in item search

The GM item browser caches glyph widths, waits briefly for typing to settle before rebuilding results, and measures item text only when needed for rendering. Opening the browser no longer builds the same grid twice.

Server lookups

Direct entity checks

Checking whether an entity pointer belongs to its pool now uses a constant-time lookup instead of scanning the pool. It removes repeated searching from that validation path.

Allocation

Create state when needed

Hate-tracking state and inventory storage use lazy allocation paths, with fixes for safe publication and cleanup when allocation fails. These changes avoid creating some state before it is needed.

The client, lookup, and allocation changes above describe implemented mechanisms. No measured speedup is claimed for them.

Additions and fixes

What players and operators gain

The work also covers everyday game behavior, tools for managing content, and a more reliable path for delivering changes.

Crafting uses the server's dice result for informed guesses. Cancelling a forge minigame releases its lock, so abandoning it does not leave the character stuck.

Inventory

More room, clearer layout

Inventory starts at 96 slots, arranged in six columns and sixteen scrollable rows. Aqua is the default theme, with dark available as an option.

Follow-up fixes preserve capacity and transferred item metadata, isolate trade operations, and strengthen temporary-bag and transactional item handling.

Updates

A signed update system

The launcher verifies signed release catalogs and updates, applies changes through recoverable transactions, and supports launcher upgrades. Installer checks reject damaged or incompatible managed installations.

Permanent signing keys and a signed release catalog replace the earlier expiring test setup.

Movement and maps

Fixes for getting around

High-speed movement stutter and world-map teleport disconnects have been addressed. Teleport coordinates were corrected across 35 maps, with a valid birth-point fallback when the requested position cannot be used.

Pets and skills

Consistent progression

Angela and Angela Junior use the normal pet fruit and ration rules. Pet equip values have been restored, and Fairy of Evil possession now reaches its EXP and drop-bonus logic.

Skill grants filter out inappropriate monster and boss combat skills. Helpful innate skills no longer replace a character's attack default.

GM tools

Tools inside the game

The /items, /help, and /worlds menus make item browsing, command discovery, and map navigation available in the client. Admin NPC services check GM authorization.

Content and diagnostics

Changes that stay traceable

Canonical content packs feed validated runtime tables. Projection checks catch differences so a generated table does not silently undo an authored fix.

Client crash diagnostics preserve native fault context and crash dumps for diagnosing failures.

Latest source changes

October 7 additions

Committed project work. Availability depends on the installed client and server revision.

  • Gem bonus coverage. Nine missing client bonus mappings were added, bringing coverage to all 53 gem mappings.
  • Gem-tier grants. GM item grants can select gem tiers, with validation at the server boundary.
  • Stat-specific pet food. Fifteen foods add stat selection to the GM pet-food tools while preserving existing item IDs and level caps.
  • Inventory corrections. Capacity, transfer metadata, and trade isolation received another round of fixes.
Windows client

Install and play

Install the full online client 1.1.0, then open its launcher. This inventory release installs in its own Tales of Pirates DX Online Inventory folder and preserves your earlier installation.

Moving to the 96-slot inventory

Existing characters reset once to 96 slots and can use all six expansion items again. If an item occupies slot 96 or above, the reset waits until those slots are empty and you reconnect.
